# v39 实现审阅前固定验收清单

本清单在独立实现审阅前由 Single Writer 固定；来源审阅保持独立。

1. 原账本八字段 overall REPAIR，逐维 REPAIR=0；本轮八条 read_clear CONDITIONAL，其余24条不关闭，不升正式 Gold。
2. 固定未屏蔽配置、每通道 HIGH=70°C、共享 CRIT=90°C 的测试设置，不宣称 POR 配置；OPEN、写配置、阈值动态更改、实际 I2C 原子性及模拟 ADC 不在运行接口内。
3. Figure 4/6 请求解释：SR1 0x02 / SR2 0x35 返回读前投影，分别清本地址标志，不影响另一地址；重复读取不凭空重置高。
4. 持续超温时，读后数字标志清零；只能由相应通道新资格化转换完成重新置位。仅采样、别的通道完成、另一地址读取均不得重置该通道位。顺序 L→D2→D1→D3，完成必须匹配未消费采样身份，拒绝重复、错序、过期及畸形事件且不改变状态。
5. INT / T_CRIT_A 原因与标志存储分离；物理故障持续、固定未屏蔽配置时任意次数读取不得释放逻辑引脚。多故障跨地址保持聚合。
6. 保留 SR1 A8 / SR2 48 必须为0；各字段掩码与原手册一致。OPEN 位不发生事件且不算八字段验证。
7. §1.3 / Figure6 内部冲突独立记录，common_source 读取持续 CRIT 后未知；下一次相应明确超温转换恢复已知置位。不得把请求解释升为来源冲突已解决。
8. HIGH >阈值断言、<=阈值后读允许退役；CRIT >断言、<后读允许退役。CRIT 等值及读在恢复前的历史顺序保留边界；本轮不宣称恢复顺序闭环。
9. 时间元数据：表格460ms typ/600ms max，正文约480ms整轮、约120ms通道、采样之后约60ms更新。没有墙钟驱动、真实设备或无条件0..600ms重置高保证。
10. 独立非零行为测试与实际执行的合成故障探针；准入只验证精确源字节、库存、协议、元数据、事件及回放。缺失真实见证PARTIAL，伪造/重复/类型混淆/来源字节改变REJECTED；回放不能替代独立行为预期。
