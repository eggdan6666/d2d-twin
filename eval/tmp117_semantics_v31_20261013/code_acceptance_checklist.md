# Independent TMP117 v3.1 acceptance checklist

Reviewer task `tmp117-v31/code_review`, project `d2d-twin`, family M, stage M4. This is an independent AI specialist review, not silicon or manufacturer certification. Checklist prepared before inspecting the new implementation; passing tests will support only the bounded clauses tested. Stage authority remains with the SCI-Skills orchestrator.

Primary source: `corpus/data/raw_pdf/TI/TMP117.pdf`, SNOSD82D, revised September 2022. SHA-256 `afe974873c80a7a4e1d342e9044e71c6f905caf4f04c1f0ea0df5c6ba35f980e`. Printed pages 12,14-19,25-32 were read directly from the original PDF. Pages 27-28 were rendered and visually checked for field positions and footnotes. No external API or new package installation. The later p17 THERM review added mode/polarity and retained CONFIG-read checks.

1. EEPROM writes must be distinguishable from scratch writes for CONFIG, THIGH, TLOW, TEMP_OFFSET. Lock EUN=0 permits volatile changes without programming. Unlock EUN=1 starts a programming operation, changes both Busy mirrors, and only a valid explicit completion persists data; p18, p30 Table7-10.
2. CONFIG stored-mask oracle must be exactly 0x07FC: MOD0, CONV[2:0], AVG[1:0], T/nA, POL, DR/Alert. MOD1 must not persist; p27 Figure7-14 and p28 footnotes. Programmed one-shot mode must start in operational shutdown after reload, not auto-trigger a new conversion; p15.
3. POR load must restore the programmed NVM image, clear EUN and Busy at completion, and restore temperature sentinel 0x8000 until a complete result; pp12,18,26. CONFIG and limit writes during initial POR are ignored; p18. Offset writes during POR lack this explicit ignore rule and must remain excluded or receive independent support.
4. Writes during programming and conversions while EUN=1 must be rejected as out-of-profile operations, without fabricating silicon behavior; p18. Unexpected/extra/missing events, unknown registers, invalid types and widths, malformed payloads must not leave partial internal-state changes.
5. MOD=1 is operational shutdown; MOD=2 has continuous behavior and reads back 0 (Table7-6 p27). MOD=3 triggers one-shot, AVG count is 1/8/32/64, no data-ready or temperature commit before completion; pp12,15,27. After one-shot, operational shutdown is required, but this review must not invent an exact post-completion MOD readback when not uniquely specified.
6. AVG must be accumulated, not running. Independent oracle values use nonconstant signed samples with an exact integral mean to avoid undocumented hardware rounding; pp12,27. Nonintegral mean must remain rejected/unknown unless source gives a numeric rounding oracle.
7. Offset is a signed two's-complement code applied to the linearized result, saturating at min/max when out of range; p31 Table7-13 and prose. If implemented, use positive/negative and overflow cases; samples denote supplied digital linearized values, not real sensor voltages.
8. TEMP or CONFIG reads clear DATA_READY, returning the old value before side effects; p27 Table7-6. Alert mode HIGH/LOW clears on CONFIG read, THERM does not; pp16-17,27. Nonzero temperature and threshold stimuli must distinguish correct side effects from all-zero behavior.
9. Source-conflicted SOFT_RESET, DEVICE_ID revision nibble, EEPROM2 reset must stay outside the numerical oracle. Unknown EEPROM identity must not be replaced by factory zero. No behavior of EEPROM1/2/3 may be claimed solely from the 572-field inventory's missing fields.
10. Admission closure records must cite concrete check IDs, preserved primary-source locators and correct field dimensions; no empty checks or foreign-chip trace. A bounded TMP117 test pass cannot admit all 20 chips or convert previously source-excluded facts to PASS.

Meaningful synthetic faults planned: locked-write persists; programming commits early; Busy mirror absent; CONFIG MOD1 persists; incorrect AVG count; averaging last sample only; no operational shutdown; offset treated unsigned/wraps; premature DR; invalid event mutates state; unsafe source-conflicted readback admitted. Their rejection is a test of oracle sensitivity, not new empirical model performance. The finished suite additionally tests logical ALERT selection/polarity/THERM retention, nominal Table7-7 metadata, and corrupt or fabricated admission evidence.

Exactly 32 independent cases inspect Table7-7 nominal metadata rather than elapsed physical time. These are bounded implementation clauses, not full 572-field admission.
