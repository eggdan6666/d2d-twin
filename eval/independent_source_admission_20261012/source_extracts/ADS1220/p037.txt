 8.5.2 Data Format

The device provides 24 bits of data in binary two's complement format. Use Equation 15 to calculate the size of
one code (LSB).

    1LSB = (2 × VREF / Gain) / 224 = +FS / 223                                                               (15)

A positive full-scale input [VIN ≥ (+FS – 1LSB) = (VREF / Gain – 1LSB)] produces an output code of 7FFFFFh and
a negative full-scale input (VIN ≤ –FS = –VREF / Gain) produces an output code of 800000h. The output clips at
 these codes for signals that exceed full-scale.
