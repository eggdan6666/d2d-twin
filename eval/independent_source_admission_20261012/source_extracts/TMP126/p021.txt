 8.5.2.4 Read Operations

 Data is read from the TMP126 by setting the R/W bit of the command word to 1. Data can be continuously
 read from a single register by setting the auto-increment bit to 0 in the command register. Figure 8-13 shows an
example of a repeated data read from a single register. Repeated temperature reads are not supported.
