 8.6.9 Slew_Limit Register (Address = 08h) [reset = 0500h]

 This register is used to configure the temperature slew rate limit of the TMP126. The limit is formatted in a 13-bit
 unsigned format with the LSB (Least Significant Bit) equal to 0.03125°C/s. The range of the register is 0°C to
 +256°C. The default value on start-up is 0140h or 10°C/s. The slew rate limit will trigger a slew rate alert on
 positive slew rates that are greater than the unsigned limit as enabled by the Alert_Enable register.

 8.6.10 Unique_ID1 register (Address = 09h) [reset = xxxxh]

 This register contains bits 47:32 of the Unique ID for the device. The Unique ID of the device is used for NIST
 traceability purposes.
