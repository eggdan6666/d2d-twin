 8.6.1 Temp_Result Register (Address = 00h) [reset = 0000h]

 This register stores the latest temperature conversion result in a 14-bit two's complement format with a LSB
 (Least Significant Bit) equal to 0.03125°C.

 8.6.2 Slew_Result Register (Address = 01h) [reset = 0000h]

 This register shows the latest slew rate calculation. Two consecutive measurements in continuous conversion
mode are required before a result is shown. When not in continuous conversion mode the register will return to
 the default value.

The slew rate result is depicted in 14-bit twos-complement format with the LSB equal to 0.03125°C/s. The
TMP126 does not accurately report negative slew rate values and bit 13 of the output result can be used to
 indicate a negative slew rate but the output value cannot be guaranteed.
